# Hindustan Unilever Limited (HUL) – DCF Valuation Model

## Project Overview
This project presents a Discounted Cash Flow (DCF) valuation of Hindustan Unilever Limited (HUL), one of India's leading FMCG companies.

The objective is to estimate the company's intrinsic value by analysing historical financial performance, forecasting future cash flows and applying an appropriate discount rate.

## Valuation Methodology

The project follows a structured DCF valuation approach:

1. Historical Financial Statement Analysis
2. Revenue Forecasting (FY2027–FY2031)
3. EBITDA and EBIT Projections
4. NOPAT Calculation
5. Free Cash Flow to Firm (FCFF) Estimation
6. Weighted Average Cost of Capital (WACC)
7. Terminal Value Calculation
8. Enterprise Value and Equity Value Estimation
9. Sensitivity Analysis

## Key Model Assumptions

| Parameter | Assumption |
|---|---:|
| Risk-Free Rate | 6.50% |
| Equity Risk Premium | 5.50% |
| Levered Beta | 0.57 |
| Cost of Equity | 9.65% |
| Pre-tax Cost of Debt | 7.00% |
| Tax Rate | 25.00% |
| WACC | 8.54% |
| Terminal Growth Rate | 5.00% |

## Key Areas of Analysis

- Revenue growth and profitability trends
- Operating margin assumptions
- Free cash flow generation

- Terminal value dependency
- WACC and terminal growth sensitivity

## Key Risks and Considerations

- Revenue growth may differ from projected assumptions.
- Inflation and input costs may impact operating margins.
- Changes in WACC can significantly affect intrinsic value.
- Terminal value represents a substantial portion of enterprise value.
- Competition and changing consumer preferences may affect future performance.

## Conclusion

The project demonstrates the application of the DCF methodology to estimate the intrinsic value of HUL.

The valuation highlights the importance of cash flow forecasting, discount rate assumptions and terminal value in determining a company's estimated worth.

The final investment view should be based on validated calculations and updated market data.
